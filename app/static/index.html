Is this service really free?

Yes, this first-release tool is free to use and does not require an account. Public hosting has per-file and computing limits.

Can I set the exact width, height and KB size?

Yes. You can set dimensions and a maximum file size. Some combinations are physically impossible without damaging image quality, so we return a clear message instead of silently changing your chosen dimensions.

Can I crop my image manually?

Yes. Select an image and use Crop your image to drag the area you want to keep or enter pixel coordinates. Its dimensions appear before conversion.

Will PDF to Word preserve everything?

Version one extracts selectable PDF text to an editable Word document. It does not guarantee layout fidelity and cannot yet OCR scanned pages.

Can I convert a video to MP3?

Yes. Select Audio, upload your own supported audio or video, choose MP3, and set an optional maximum size. This tool does not download media from third-party streaming services.
